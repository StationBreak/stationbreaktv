# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately by email to **security@stationbreak.tv**.

**Don't report them in public issues, pull requests or discussions.** A public report tells everyone about the
problem before there's a fix.

To help us reproduce and fix the problem, please include:

- what the vulnerability is and what an attacker could do with it;
- the steps to reproduce it, or a proof of concept;
- the StationBreak build you found it in (for example, the commit SHA or the APK's file name), and the device and
  Android version.

## Supported versions

StationBreak has no release yet. Until there is one, only **the latest `main` build** is supported, and fixes go
to `main`.
