# Guide A tokens

Status: Phil chose direction A, the soft solid-orange focus treatment. Light mode is its matching theme, not a new layout.
Scope: Guide only. This file is a design reference for StationBreak Build, not a merge approval or a change to app navigation.

## Source and replacement

- Dark reference: `guide-A-soft.png`.
- Light reference: `guide-A-soft-light.png`.
- Full-resolution comparison: `guide-A-dark-light-compare.png`.
- Shared source: `render.py`, function `make`, themes `A` and `AL`. Both use the same content, geometry, and typography.
- Browser preview: `guide-polish.html`. Each theme has its own SVG paint IDs.
- Machine-readable colours: `guide-A-theme-tokens.json`. Keys `A` and `AL` mean dark and light.
- Contrast calculations: `guide-A-contrast-audit.json`, regenerated by `python3 audit-a.py` after `python3 render.py`.

These Guide tokens replace the earlier `BroadcastFocus` treatment with its Cream outset ring and Ink gap. The new focus is a filled orange rounded surface. There is no ring or Ink gap. No inherited border, ring, or default TV focus halo appears in addition to this treatment.

Space Mono is replaced by Manrope throughout the Guide. Archivo Black is no longer used in the Guide. These changes do not authorize a global font or focus change on other screens.

The page has a quiet diagonal gradient from `pageGradientStart` to `page` at 60%, then stays at `page`. Programme cards are opaque. Alternate rows use `cardAlternate`. There are no card borders.

The dark progress track changes slightly from `#45433D` to `#3E3C36`. Progress-fill contrast improves from 2.96:1 to 3.30:1. The picked dark layout and all content stay the same.

Light mode uses deeper orange because the original orange does not provide enough contrast for every light-theme use. `#C9531F` also fails the 4.5:1 text requirement with white text. The chosen `#B74719` passes with white and with the light page.

Channel numbers, timeline text, remaining time, menu labels, and hints use full-opacity text roles. Muted text is a colour, not reduced alpha.

The live picture remains dark in both themes. Its LIVE chip and station caption retain their dark-theme colours. Video overlay text is on a dark scrim, not directly on unpredictable footage.

The minimum font size is 16sp, equivalent to 24 reference pixels. On a smaller logical viewport, fewer visible rows and scrolling take precedence over smaller text. Safe areas are at least 5% of each actual screen dimension.

## Focus behaviour

The programme under D-pad focus uses `focusFill` and `focusText`. Fill contrast provides the focus indication without a border. Only one navigation target has this treatment at a time.

The focused surface extends 3 reference pixels horizontally and 2 vertically beyond its resting bounds. The title stays in place and does not scale. The draw-only extension leaves grid measurement and neighbouring cells unchanged. At the reference half-hour width this is a 461 by 68px surface around a 455 by 64px cell.

This extension is not an outset ring. The entire extended rounded surface has the same orange fill. Content scale is 1.0. No cream outline, inner stroke, dark gap, or pulse is present.

The reference shadow is a set of soft-looking rounded layers behind the orange surface. Their offsets are 10, 7, and 4 reference pixels downward, with 2px horizontal expansion and 20px corner radius. Dark opacities are 4.5%, 7%, and 12%. Light opacities are 3.015%, 4.69%, and 8.04%, using the warm shadow colour. Compose may use a single blurred shadow with the same light visual weight. The shadow is not included in the contrast claim.

The focused row gets a subtle wash behind its metadata and cards. A short orange tick appears beside the channel number. Neither replaces the focused programme's solid fill. Off-row text keeps its normal weight and secondary colour.

A proposed motion token is 160ms ease-out for fill, surface extension, and shadow. With reduced motion, state changes are immediate. The static references do not approve a new navigation rule or a content-scale animation.

## Menu and NOW states

The screenshot's Channels pill is a quiet selected or primary-action treatment, not D-pad focus. Settings and Exit are transparent at rest. A menu target under D-pad focus uses `menuPillFocused` and `menuTextFocused`, with no ring and no scale. The pill stays fully rounded. Existing menu navigation and action semantics stay unchanged.

The details NOW chip uses its own fill and text roles. The timeline NOW chip uses the same colours with a capsule shape. Both stay compact, with 24px bold labels. NOW, the progress fill, and the rail share the theme accent. They remain visible when focus moves to the menu.

## Minimum contrast

Ratios use WCAG sRGB relative luminance. Values refer to solid colours, not shadow or antialiasing. The page entries use the worst gradient stop for each theme. Focus-fill contrast is against opaque resting neighbours.

| Pair | Dark | Light | Minimum |
| --- | --- | --- | --- |
| Focus fill / adjacent card | 4.33:1 | 5.22:1 | 3:1 |
| Focus fill / alternate card | 4.51:1 | 5.00:1 | 3:1 |
| Focus fill / darkest or lightest page stop | 4.70:1 | 4.62:1 | 3:1 |
| Focus text / focus fill | 5.16:1 | 5.35:1 | 4.5:1 |
| Primary text / page | 13.57:1 | 14.87:1 | 4.5:1 |
| Secondary text / page | 7.52:1 | 5.65:1 | 4.5:1 |
| Secondary text / selected menu or key pill | 5.32:1 | 4.70:1 | 4.5:1 |
| Secondary text / resting card | 6.93:1 | 6.11:1 | 4.5:1 |
| Programme text / resting card | 10.66:1 | 16.09:1 | 4.5:1 |
| Supporting text / page | 9.70:1 | 5.65:1 | 4.5:1 |
| Accent text / page | 4.70:1 | 4.62:1 | 4.5:1 |
| NOW text / NOW chip | 5.16:1 | 5.35:1 | 4.5:1 |
| Progress fill / track | 3.30:1 | 3.42:1 | 3:1 |
| Focused menu / selected background | 3.84:1 | 3.84:1 | 3:1 |

Every pair passes its minimum before rounding. All secondary text remains at least 4.5:1. Light secondary text is 5.65:1 on the paper page and at least 4.70:1 on the specified darker light-theme pills. Focus is at least 3:1 without any shadow.

The thin hint divider and low-opacity row wash are decorative, not control boundaries. Resting cards are separated by gaps, not high-contrast borders. A colour role alone does not guarantee contrast on arbitrary imagery, disabled alpha, or another component's background.

## Remaining product choice

The references do not choose how theme selection works. Dark as the initial default, with an explicit Light option, fits Phil's stated preference. Following the system theme instead is a separate product decision. No theme settings screen is specified here.

A real Compose render on a Fire TV remains necessary for viewing-distance legibility, clipping, safe area, focus movement, and text scaling. These files are design references, not hardware captures.
